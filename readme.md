# Generative Jamdani — Pix2Pix

This project is an interactive web app that uses [ml5.js](https://ml5js.org/) and [p5.js](https://p5js.org/) to generate Jamdani textile motifs using a Pix2Pix machine learning model.

## Features

- Draw your own sketch or select a preset motif.
- Adjust brush size.
- Generate a Jamdani motif using the AI model.
- Clear the canvas or load a random preset.

## Getting Started

1. **Clone or download this repository.**
2. **Open `index.html` in your browser**  
   or  
   **Use Live Server in VS Code** for live reloading.

## Project Structure

- `index.html` — Main web page
- `app.js` — Application logic (drawing, model interaction)
- `style.css` — Styles
- `images/` — Preset images
- `model/` — Pix2Pix model files

## Requirements

- No installation needed. All dependencies are loaded via CDN.
- For best experience, use a modern browser.
